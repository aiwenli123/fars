# FARS Levitt–Porter Replication and BAC Extensions

This repository contains R code for analyzing fatal crashes in the 2015–2024 Fatality Analysis Reporting System (FARS), including analyses using observed and multiply imputed blood alcohol concentration (BAC).

## Repository structure

- `code/`: Data preparation, model estimation, diagnostics, sensitivity analyses, and figures.
- `data/raw/`: Original yearly FARS files downloaded from [NHTSA](https://www.nhtsa.gov/file-downloads?p=nhtsa/downloads/FARS/). These files are not included in the repository.
- `data/processed/`: Cleaned analysis datasets and model outputs generated by the scripts.
- `figures/`: Figures generated by the analysis scripts.

## Main datasets

- `driver_analysis_lp_2015_2024.csv`: Cleaned driver-level sample of nighttime fatal crashes involving one or two vehicles.
- `lp_crash_types_2015_2024.csv`: Crash-level classifications for the binary sober/drinking analysis.
- `driver_miper_wide_2015_2024.csv`: Driver-level data containing all ten FARS BAC imputations in separate columns.
- `driver_miper_long_2015_2024.csv`: Analysis-ready version with one row per driver and imputation.
- `four_group_crash_counts_by_cell_imp.csv`: Crash counts by analysis cell, imputation, and BAC-group combination.
- `four_group_overall_counts_avg.csv`: Overall crash counts averaged across the ten imputations.
- `four_group_mle_estimates_pooled.csv`: Final four-group risk estimates pooled across imputations.
- `four_group_mle_cell_exposure_ratios.csv`: Estimated BAC-group exposure ratios within each analysis cell.

Other files in `data/processed/` contain intermediate results, diagnostics, sensitivity-analysis outputs, and plotting data.

## Script overview

Scripts are numbered in their intended order:

- `00`–`03`: Read, clean, and describe the FARS data.
- `04`–`09`: Estimate and evaluate the binary Levitt–Porter model, including the multiple-imputation analysis.
- `10`–`12`: Prepare, estimate, and summarize the four-BAC-group model.
- `13`: Conduct sensitivity analyses for the model assumptions.
- `14`: Create final figures and policy-motivation statistics.
